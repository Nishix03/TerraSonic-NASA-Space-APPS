La selección conserva el fallo de memoria del driver Firefox y su repetición correcta como evidencias distintas; no incluye credenciales, snapshots de heap ni logs privados de despliegue.

Para usar el paquete: extraer en una carpeta nueva, ejecutar `python verify_package.py` y después `python serve.py`, con Python 3.10 o posterior. Abrir la dirección local que indica el servidor y detenerlo con Ctrl+C. No se requieren Node, Blender, cuenta ni backend para usar el producto. La huella de cada ZIP identifica su fuente; los checkpoints anteriores se conservan.
