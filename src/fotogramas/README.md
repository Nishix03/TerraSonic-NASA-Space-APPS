# Módulo M1 · fotogramas

Fotogramas EIC: manifiesto de discos (data/discos.json) y extracción de imágenes del video oficial del EIC (scripts/descargar_fotogramas.py). Los discos son ventanas de 150 días de 2024–2026; el protagonista de cada uno es un personaje.

- Contrato público: `docs/CONTRATOS.md`, sección M1. Plan detallado: `docs/PLAN.md` §8.
- Solo el dueño edita esta carpeta. Para pedir cambios, abre un issue con la etiqueta `fotogramas`.
- Mientras otro módulo no esté listo, usa datos simulados en lugar de esperar.
